# Footprint `OpenPatch:ISP1807` (Insight SiP ISP1807-LR, nRF52840 SiP) - VERIFIED

Status: **verified against manufacturer data** (replaces the earlier "placeholder" note).

Sources (downloaded into `../datasheets/isp/`, git-ignored copies):
- Datasheet `isp_ble_DS1807.pdf` R19: section 3 (pin table), 4.1 (mechanical drawing), 4.2 (SMT guidelines), 4.3 (antenna keep-out).
- Official Insight Eagle library `ISP1807_Eagle_Library.zip` (`ISP1807LR_Int.lbr`, package `ISP1807-LR`): all 78 pad coordinates, used to generate the footprint.

| Item | Value |
|---|---|
| Body | 8.0 x 8.0 x 1.0 mm LGA, 78 pads (62 functional + NC pads 65-78) |
| Pads | 0.4 x 0.4 mm standard, 0.8 x 0.8 mm corner pads (1, 7, 25, 31, 68, 75); pitch 0.65 mm double row; paste = pad size |
| Pin mapping | pad 1..64 as in `pin-assignment.md`; pad numbers identical to the community symbol used earlier (checked pad by pad against the Eagle `connects` list) |
| NC pads 65-78 | isolated mechanical pads, must be soldered but unconnected (drop test) |
| VCC_nRF | 1.7-3.6 V (datasheet; earlier 5.5 V note was wrong) |
| Via-in-pad | Insight: 0.2 mm via / 0.4 mm catch pad, plugged and capped. The board script places a 0.2/0.4 via in every connected pad that cannot escape on L1 -> needs JLC "epoxy filled and capped" vias |
| Antenna keep-out | no metal, no traces, no components on any layer except LGA pads; datasheet zone 18 mm min wide x 4 mm. The mechanical layout reserves x 31.2-39.8, y 26.4-31.1 mm (8.6 mm wide). **This is narrower than the 18 mm minimum**: antenna efficiency/range will be reduced; measure on Rev A |
| Orientation | antenna half (local +Y, pads 65-78 side) pointing to +Y of the mechanical frame |

Regenerate: `kicad/gen_footprints.py` (reads the Eagle library).
