# Standards matrix

> **Test project, not a medical device; never worn, never filled with insulin or any drug (water only).** The matrix maps the standards a legal manufacturer would apply to the evidence in this repository. Editions are those I know of or confirmed on 2026-11-19; **[VERIFY]** marks anything to be checked against the current Official Journal list (Implementing Decision (EU) 2021/1182 as amended) and the FDA Recognized Consensus Standards database. Clause lists are indicative, not a substitute for the purchased standards.

**Status legend**

| Code | Meaning |
|---|---|
| HAVE | evidence exists in the repo (design stage) |
| SIM | can be done or already done in simulation / host test |
| BENCH | needs bench work (water only) on hardware; can be done by the open project |
| LAB | needs an accredited laboratory |
| CLIN | needs human-subject evidence (sponsor, never this project) |
| LM | needs a legal manufacturer (QMS, entity, or drug-related evidence that this project never generates) |

Drug-related evidence (drug compatibility, insulin stability, biocompatibility with insulin, E&L with the drug) is **LM only**: this project is water only (decision 2026-11-19).

### 3.1 Where our spec §7 values differ from the standard's test conditions

1. **Quantity vs rate.** Spec §7 and the safety plan state doses in units (U) and tolerances per dose; the standard states flow rate accuracy over time. A conversion (1 U = 10 uL for U100 equivalent) and a rate-based test plan are needed. At 0.5 U/h (5 uL/h) the test must resolve about 0.14 uL per step; a 0.1 mg balance resolves 0.1 uL of water, so resolution and evaporation control are limiting.
2. **Occlusion criterion.** Spec §7: alarm at <= 2 U undelivered. Standard: pressure and time at alarm, plus volume on release. The simulation (REPORT 5.4) shows the 2 U criterion alone gives 2.5 to 5.2 U undelivered including stored volume. Spec §7 may not be relaxed silently; a new requirement (pressure/time criterion and a post-release bolus limit) must be **added** with a STATUS entry.
3. **No short-term accuracy requirement** (trumpet curves) and **no air-in-line / free-flow requirements** in spec §7. Adding requirements strengthens, not relaxes, the spec.
4. **Alarm priorities**: spec §7 does not map conditions to IEC 60601-1-8 priorities.
5. **Temperature and pressure conditions**: the standard fixes ambient and back-pressure conditions for the accuracy tests; the project's tests do not fix back pressure (cannula + tissue back-pressure). To be defined by the manufacturer for the intended use.

## 4. Open decisions that change the standards set

- Is the fluid path supplied sterile (then ISO 11135/11137/17665, ISO 11607, 10993-7)? Is the pod reprocessed between users (ISO 17664-1)? Both are manufacturer decisions.
- Is the app a separate medical device (IEC 82304-1) or part of the pump system?
- Which controller and CGM interoperability claims (ROADMAP section 2)?
- Whether Rev B retains the contact-charging pads or Qi (affects 60601-1 leakage and 60601-1-2).
