# 03 Software requirements specification (IEC 62304 5.2), derived from spec, protocol and diagnostics

> Test project. Requirements here are **derived** from `../../spec/design-parameters.md` (sections cited), `../../docs/02-safety.md`, `../../docs/04-protocol.md`, `../../docs/06-diagnostics.md`. The spec remains the single source of truth: change it there first. Verification names refer to real tests (checked by file/function for the hazard chain by `../tools/trace.py`; this table is a working SRS and should be given requirement IDs in code comments over time).
>
> Class: C unless stated (see `01-safety-classification.md`). Status: V = verified by host test/simulation (design stage; **not on hardware**), P = planned.
