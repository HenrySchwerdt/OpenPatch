## Open work, in order

1. **Electronics: place + route the 45-part board** on the corrected outline (review fixes in `cupgeom.py`/`place_cup.py`, screw holes from bfed7e7 → Ø1.4 NPTH + Ø2.8 keep-out), Freerouting with a timeout (`flow_cup.sh`, `OP_TIMEOUT`), DRC 0. Fallback: `cup/ROUTING-GUIDE.md` for a manual KiCad finish; old 91-part routed board `cup_v4r91_routed.kicad_pcb`. Then JLC package (Gerber/BOM/CPL), `COST.md`, `ORDER.md`.
2. **Independent pin check before ordering** (not done yet): pull official LCSC symbols/footprints (`easyeda2kicad`) for every part and compare pin-by-pin with the netlist and datasheets (the TPS61023 pinout was wrong once). Also verify: HJ-840 land pattern + antenna keep-out vs the JLC footprint of C50052094, DRV8835 WSON-12 pattern, USB-C C223907 pattern, nRF52840 REG0 external load limit (4–7 mA estimate), STM32C011 BOOT0 internal pull-down (DS13866), sounder stray field vs dock hall (bench).
3. **SPICE** (KiCad ngspice + TI models) of boost start-up, TPS2553 limit/fault → latch, enable logic; optionally Renode for firmware on nRF52840.
4. **Mechanics: adapt CAD to real parts** from `docs/BUY-LIST.md`: miter pair module 0.3 z12 (OD 4.02) instead of z16, angle-magnet clash with the gear fronts, nut pocket AF 3.5 (brass), no thrust sleeve (gear B tapped on the rod), collar/bush/O-ring/washer substitutes; update `docs/PARTS-LOCK.md` row 3. Then regenerate + `check.py` (height ≤ 8.5).
5. **Firmware (`firmware-rs`)**: DRV8835 driver (full-step sequence on APHASE/AENBL/BPHASE/BENBL instead of STEP/DIR), new pin map (`FIRMWARE-PINMAP.md`), UICR REGOUT0 = 3.3 V, SAADC VDDHDIV5 battery reading, signed USB DFU bootloader, supervisor flashing via ROM bootloader, supervisor watching the PHASE lines, LED patterns (charging pulse / full green / low red), burst stepping for cell peak current, occlusion now via TMAG angle shortfall only (current-rise warning dropped).
6. **Spec/doc sync**: spec §1a exception for soldered motor/cell wires; spec §4/§7 and `docs/02-safety.md` to the new cut path and occlusion detection; `docs/05-cost-model.md` with real quotes; website renders after the board is final.
7. **Measure on samples** (LOCK-AFTER-SAMPLE): Insight Flex cannula head (dock coupon), NFP shaft/lead exit, cell lead end and dimensions, gears, magnets.
