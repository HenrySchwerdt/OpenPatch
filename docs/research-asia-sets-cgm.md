# Research: cheap infusion sets from Asian marketplaces, and cheap CGMs that a self-built iOS app could read

Date: 2026-11-24. Research only. Nothing here was ordered or tested.

> **OpenPatch is a bench-only test project and must never be used on a person** (see `DISCLAIMER.md`, `docs/02-safety.md`). **Water only.** Every infusion set below is for **bench (water) tests only**: priming, occlusion and back-pressure tests into a container or a pressure sensor. **No item here is evaluated for use on a body.** Any CGM integration in this document is **theoretical**: it is about reading data on the bench. It must never close a loop with a pump that is worn.

Legend: **VERIFIED** = I read the source page itself. **UNVERIFIED** = from a search snippet, a listing without a price, or a blocked page.
Currency: CNY converted at **1 EUR ~ 8.2 CNY** (approximate, UNVERIFIED rate). Asian retail prices do not include import VAT (19 %), duty or forwarder fees.

### Ranking for small-quantity bench tests (water)

1. **Phray / 优泵瑞宇 6 mm soft separable line (JD 10232796824373), or its export version through Phray's Alibaba store.** It is the only Asian source that is both a real pump-set maker and a seller in boxes of 10. It is on the Luer (Dana/MedNovo) side of the Chinese market, and it costs about €8 per set before import. On the export side, ask for an ODM/OEM quote. **FOR BENCH (WATER) TESTS ONLY.** Before ordering, confirm in the quote that the set really is Luer, the cannula material (Teflon/FEP), and whether an inserter is included. The JD item gives no inserter, so the Apex soft-cannula inserter (169 CNY) may be needed, and it is MiniMed-style.
2. MedNovo Luer soft 8.5 mm (JD 10197147145180).
3. IPELE ES261 button soft (JD 10029780978907).
4. SOOIL Soft-Release-ST (Korea). Its maker is a recognised device company, but no shop price was found.
5. Apex Medical line + inserter. This is the source to use if a single inserter for many sets is wanted.

**Practical verdict:** no Asian export marketplace sells a Luer soft-cannula pump set with an integrated inserter in quantities ≤ 100 at a visible price. The Chinese domestic sets need a forwarder, and some have no inserter. For a first box of 10, an EU pharmacy Inset/Cleo-type Luer set (about €20-25 per set, CE, no import step) is still the lowest-risk option. Note that the pod currently docks an **Accu-Chek Insight Flex** cannula head (`docs/PARTS-LOCK.md`), not a Luer set, so a Luer set is only useful for line, occlusion and back-pressure bench tests.

### Ranking

**By cost per day (cheapest first):**
- **EU-buyable, verified:** Yuwell CT3 ~€2.75 < LinX/AiDEX €3.20 (€2.70 on subscription) < Libre 2 Plus ~€3.14 (reimbursement price) < Dexcom ONE+ €3.16-4.38 < Sibionics GS1 €4.50 < Libre 3 Plus ~€4.6 < Dexcom G7 €9.90.
- **China domestic (not EU-legal, region-locked):** Sinocare i6 ~€0.65-0.95 < Ottai M8 ~€1.04 < MicroTech GX-01S ~€1.0-1.6 < Yuwell 5Pro ~€1.5-1.9 < Sibionics split version ~€1.7 < Huawei G1 ~€2.3 < Sibionics GS3 ~€3.3.

**By feasibility of our own iOS app / Trio reading the sensor directly:**
1. **Dexcom ONE+ / G7**: Trio and xDrip4iOS support it today. With Trio, the Dexcom app must be on the phone.
2. **Libre 2 / 2 Plus (EU)**: Trio LibreTransmitter and xDrip4iOS read it directly over BLE after an NFC start. EU Libre 2 is being phased out (IE: end of March 2027), and Libre 2 Plus is the successor.
3. **Medtrum Nano**: in xDrip4iOS, but only through the running EasyPatch app.
4. **Sibionics GS1 (legacy)**: documented frame protocol and an iOS prototype exist. Current sensors with encrypted authentication do not work, and region/seller key checks apply.
5. **AiDEX X / LinX, CareSens Air**: Juggluco (Android, GPL) shows it is possible. An iOS port would be new work.
6. Libre 3, Yuwell, Sinocare, Syai, Ottai, Glunovo: closed or encrypted, with only vendor-app or patched-app routes.

**Best value with a working path today:** Libre 2 Plus (EU) at ~€3.14/day, then Dexcom ONE+ at ~€3.2-4.4/day. ### Legal / terms notes (factual, not legal advice)

- A blog post reports that **Abbott sent DMCA takedowns** against published Libre 3 reverse engineering (US law) ([frdmtoplay](https://frdmtoplay.com/freeing-glucose-data-from-the-freestyle-libre-3)).
- The Sibionics vendor app checks a **per-activation key tied to specific sellers**. The modified "Sugar Joy+" app was withdrawn ([xDrip 3063](https://github.com/NightscoutFoundation/xDrip/discussions/3063)). Patched vendor apps are a ToS/licence issue, and AAPS treats them as **not trusted** sources ([AAPS](https://androidaps.readthedocs.io/en/latest/Getting-Started/CompatiblesCgms.html)).
- The EU Software Directive 2009/24/EC Art. 6 allows decompilation for interoperability under narrow conditions (general knowledge, UNVERIFIED here). Vendor app EULAs usually forbid reverse engineering.
- Trio forbids xDrip4iOS or Glucose Direct builds from third-party TestFlight; they must be self-built with the same Apple team ([Trio docs](https://oiaps-tmhastings.readthedocs.io/en/dev/settings/devices/cgm.html)).
- China-market sensors such as Ottai, Sinocare i6 and the Sibionics split version have **no CE evidence** in our sources (or are China SKUs), so placing them on the EU market is not permitted. For OpenPatch they would at most be bench data sources.
- For OpenPatch: CGM integration stays **bench and simulation only**. Trio's own docs warn that the glucose simulator "should never be used in conjunction with a live pump" connected to a person or animal. The same applies to any OpenPatch loop.
