## cause isolation
Two further builds from the SAME source path with CARGO_TARGET_DIR names tA / tB: app.bin identical to run1 (3a0d9452...).
Differences between paths are in anonymous symbol numbering (.Lanon.<hash>.N): cargo hashes the absolute path of path
dependencies outside the workspace root (../openpatch-core, ../openpatch-proto) into -C metadata; --remap-path-prefix does not cover it.
Remedy: release builds in a fixed directory (container /build/firmware-rs). The app.bin hash above therefore only reproduces
from the same absolute path (/tmp/.../repro3/src/firmware-rs in this sandbox).
